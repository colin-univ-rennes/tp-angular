# Pokedemo

Ce projet de TP utilise Angular v20.3.0.

En suivant [le sujet](https://github.com/barais/teaching-jxs-angular/blob/master/README.md), 
j'ai implémenté un petit service de recherche et d'affichage de Pokémon pour apprendre à utiliser Angular.

## Execution

Version pnpm: 10.18.1 <br>
Version node / npm: 22.20.0 <br>
(précisé dans `package.json`)

- Installer les dépendances avec `pnpm i`
- Lancer le serveur de développement Angular avec `pnpm run start`

## Questions

### Q3bis

Quand Angular fait le data binding pour intégrer la valeur du champ dans la page, le texte est traité comme texte pur.
Si ce texte contient du code HTML valide, il ne sera pas interprété par le navigateur.
